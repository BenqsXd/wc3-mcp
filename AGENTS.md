# wc3-mcp

This repository is an MCP server (`wc3`) for making Warcraft III maps, plus the skill that explains how to use it.

When the user wants to create, edit, inspect, validate or test a Warcraft III map, campaign, AI or asset, or drive
the World Editor or the game, read `skills/wc3-map-making/SKILL.md` first and the reference files it points to in
`skills/wc3-map-making/references/`. `wc3_help(topic)` explains any tool in depth.
